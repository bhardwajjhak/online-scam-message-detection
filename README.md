
# 📱 Online Scam Message Detection System

A Machine Learning based web application to detect scam and spam messages in real-time using NLP and Streamlit.

---

# 🚀 Live Demo

👉 https://scam-detector-app.streamlit.app/

---

# 📝 Project Overview

The **Online Scam Message Detection System** identifies whether a message is **Scam/Spam** or **Not Scam**.

This system uses:
- Text preprocessing
- NLP techniques  
- Machine Learning prediction
- Confidence score analysis
- Keyword-based detection

---

# ✨ Features

- ✅ Real-time scam message detection
- ✅ Spam / Not Spam classification
- ✅ Confidence score prediction
- ✅ Keyword-based scam detection
- ✅ Simple user interface

---

# 🛠️ Technologies Used

- **Programming Language:** Python 
- **Frontend & Deployment:** streamlit/Streamlit Cloud  
- **Machine Learning:** Scikit-learn - Linear SVM Algorithm
- **NLP & Text Processing:** Regex, TF-IDF Vectorizer
- **Data Handling:** Pandas, NumPy
- **Model Persistence:** Pickle-for saving/loading model & vectorizer
- **Mathematical Operations:** Math - Sigmoid Function
